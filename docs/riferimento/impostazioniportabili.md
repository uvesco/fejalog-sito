# Conservare le impostazioni dell'app

- Identità del veterinario, nome del dispositivo, preferenze e reti salvate sono indipendenti dai progetti e restano dopo l'aggiornamento dell'APK con lo stesso identificativo e la stessa firma.
- Da Impostazioni dell'app esporta il file JSON versionato per conservarle o trasferirle su un altro dispositivo. Il file comprende anche le password delle reti. Per importare, esci prima dalla rete e controlla l'anteprima.
- I permessi delle cartelle vengono concessi sul dispositivo: dopo il trasferimento scegli di nuovo la cartella di lavoro se necessario. I progetti si trasferiscono con il loro backup.
