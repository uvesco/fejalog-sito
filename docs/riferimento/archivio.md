# Archivio e copie del progetto

- In Impostazioni › Cartelle scegli una volta la cartella locale dei backup e la remota. Nel selettore compaiono solo i servizi che permettono di scegliere una cartella.
- Configurazione › 1. Parametri e regole › File del progetto raccoglie le destinazioni del progetto: qui scegli cartelle e copie prima di caricare i dati.
- Le assegnazioni iniziali e le modifiche/scambi delle provette delle pecore conservano nuovi CSV della numerazione, sempre sul dispositivo e nella cartella di progetto quando disponibile.
- Puoi scegliere una seconda cartella, anche su chiavetta USB riconosciuta da Android. La copia è incrementale: solo file mancanti, nessuna sovrascrittura. Se la destinazione è scollegata, le copie restano disponibili sul dispositivo.
- Impostazioni della profilassi e reti si definiscono in Configurazione; i capi ricercati sono in Configurazione › 3. Dati input; sostituzioni e caricamenti di registri BDN in Configurazione › 3. Dati input › Registri BDN e contrassegni.
